# Generic hand meshes

Left and right rigged hand GLB files from `@webxr-input-profiles/assets`, generic-hand profile (1.0 release series), downloaded from:

- https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/left.glb
- https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0/dist/profiles/generic-hand/right.glb

Source project: https://github.com/immersive-web/webxr-input-profiles

Assets package license: MIT, Copyright (c) 2019 Amazon. The complete license is included in HAND-MODEL-LICENSE.txt.

The app retargets the rig to webcam landmarks and applies its own glove materials. No WebXR headset is required.
